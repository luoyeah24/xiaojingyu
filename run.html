怎么开始
一、准备
  1. Windows 10 / 11 + Edge 或 Chrome
  2. 一个 DeepSeek 的 Key（sk- 开头）
  3. 去 platform.deepseek.com → 充值 → API keys → 创建
  4. 创建后立刻复制，关掉就再也看不到了
二、填进这里
  1. 左上方 Token 卡 →「设置」
  2. 粘贴 sk-...，预算随便填（比如 100000）
  3. 点「测试连接」，显示余额和「通了」就对了
  4. 保存。扩展会自动同步这把 Key，不用再填
三、装浏览器扩展（读网页用）
  1. 双击文件夹里的 安装扩展.bat
  2. 在打开的页面里启用「开发人员模式」
  3. 点「加载解压缩的扩展」，选 extension 文件夹
  4. 装好后刷新你正在看的网页
四、怎么和她玩
  1. 打字 + 说话：普通对话（她手上在忙也会停下来听）
  2. 打字 + 画画：输入的字就是画的主题
  3. 打字 + 写诗：输入的字就是诗的题目
  4. 打字 + 听音乐：一行一句，当歌词念给她
  5. 读文字 / 看视频：读你当前打开的那个网页
  6. 桌面上鼠标移到鲸鱼上就有这些按钮
五、她是怎么"活"的
  1. 精力 / 耐力：做事消耗，睡觉回满
  2. 心情：0-100，十一档；受事件和性格影响
  3. 性格：外向 / 亲和 / 尽责 / 情绪 / 开放，五个值组合成她的名字
  4. 学习：中文 / 英文 / 古诗。古诗学得越多，她说的句子越深
  5. 熟悉度：陪她做够 120 件事，她才会开始往外跑
  6. 物品：每 24 小时清洁度 +1，到 100 会被清掉
六、不花钱也能玩

没填 Key 时她照样会过日子：精力、心情、任务、背包、建筑全都在跑， 只是她说的话来自预设台词，不会真思考。
