🐳 小鲸鱼

一只住在你桌面上的 AI 小鲸鱼。
她自己做事、有心情、会变性格，用你自己的 token 读网页、写诗、画画、唱歌。

📦
小鲸鱼 v0.5
Windows · 解压即用 · 需要自己的 API Key
下载

装它需要三步

  1. 解压到一个固定的文件夹（以后别移动）
  2. 双击 启动鲸鱼.bat —— 桌面右下角会出现一只鲸鱼
  3. 双击 安装扩展.bat，按提示把 extension 文件夹加载进浏览器

然后填一次 Key

  1. 点桌面上的鲸鱼 → 打开面板
  2. Token 卡 →「设置」→ 粘贴 sk-... → 保存
  3. 扩展会自动拿到同一把 Key，不用再填第二次

它能做什么

读网页鼠标移到鲸鱼上，点「读文字」，她读完在头顶冒出摘要。
写诗 / 画画输入主题再点按钮。学的古诗越多，写得越深。
听音乐她没有耳朵，只能读歌词——但会哼，而且用系统语音唱出来。
自己过日子精力、耐力、心情、疲劳、崩溃，全都在跑。
大五人格外向 / 亲和 / 尽责 / 情绪 / 开放，组合成她的名字。
会变做的每件事都会推动性格，养久了就不是当初那条鱼。
关于隐私：所有数据都在你电脑上（127.0.0.1:8787），不经过任何服务器。 API Key 存在本地的 apikey.json 和浏览器 localStorage，只用来直连 DeepSeek。

关于花钱：她只在「说话 / 读网页 / 写诗 / 画画 / 自由活动」时调 API。 不点就不花钱。自由活动开着会持续消耗，间隔可以调。
