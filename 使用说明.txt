小鲸鱼 v0.5 使用说明
================================

一、这是什么
--------------------------------
一只住在桌面上的 AI 小鲸鱼。
她会自己做事、有心情、会变性格，还能用你自己的 token 读网页、写诗、画画、唱歌。

全部数据都在你自己电脑上，不联网上传（除了调用你自己的 API）。


二、装之前需要
--------------------------------
1. Windows 10 / 11
2. 一个 DeepSeek 的 API Key（sk- 开头）
   去 platform.deepseek.com 注册 → 充值 → API keys → 创建
3. Edge 或 Chrome 浏览器


三、装（三步）
--------------------------------
第 1 步：双击「启动鲸鱼.bat」
   会起一个本地服务 + 桌面上出现一只鲸鱼。
   第一次可能要点两次，因为服务要启动。

第 2 步：装浏览器扩展
   双击「安装扩展.bat」，它会打开扩展页面。
   然后：
     - 打开左下角「开发人员模式」
     - 点「加载解压缩的扩展」
     - 选择 extension 这个文件夹

第 3 步：填 Key
   点桌面鲸鱼 → 打开网页面板 → Token 卡「设置」→ 粘贴 sk-...
   保存后，扩展会自动拿到同一把 Key，不用再填第二次。


四、怎么玩
--------------------------------
鼠标移到桌面鲸鱼上：
   [读文字]  读你当前打开的网页
   [看视频]  读视频页的标题/简介/评论（看不到画面）
   [画画]    按输入框里的文字画一张
   [听音乐]  把输入框里的字当歌词，念给她听

输入框 + [说话]：正常对话（会打断她手上的事）

网页里的东西：
   左侧：我的鱼 / Token / 特殊活动 / 任务 / 背包 / 建筑 / 垃圾桶
   右侧：状态 / 接下来想做什么 / 爱好 / 命令 / 日志


五、她怎么"活"
--------------------------------
精力 / 耐力：做事会消耗，睡觉回满
心情：0-100，十一档描述，受事件和性格影响
性格：大五人格（外向/亲和/尽责/情绪/开放），组合成名字
学习：中文 / 英文 / 古诗，学得越多说得越难
熟悉度：做得越多，越敢往外跑

她会自己按权重挑事做，也会自己决定"想做什么"。


六、常见问题
--------------------------------
Q: 点读文字没反应？
A: 看桌面鲸鱼下面有没有提示。没有绿点 = 扩展没连上，去 edge://extensions 重新加载。

Q: 提示"还没有 API Key"？
A: 在网页 Token 卡的「设置」里填一次，保存。扩展会自动同步。

Q: 一打开就自己读网页？
A: 已经修了，只处理打开页面之后的记录。如果还有，把 read.json 删掉。

Q: 画画总是画不出来？
A: 模型写 SVG 的能力有限，画不出来会自动转成对话。

Q: 关掉浏览器后她会死吗？
A: 桌面那只还在，只是网页状态停了。重新打开 http://127.0.0.1:8787/run.html 继续。

Q: 端口 8787 被占用？
A: 说明已经开着一份，先关掉再开。


七、文件说明
--------------------------------
启动鲸鱼.bat      ← 日常就双击这个
安装扩展.bat      ← 只在第一次装扩展时用
server.ps1        ← 本地服务（127.0.0.1:8787）
shell.ps1         ← 桌面上的鲸鱼
run.html          ← 完整面板
extension/        ← 浏览器扩展（2 个文件）
avatars/          ← 形象图片，放进去就能在设置里选


八、想换形象
--------------------------------
把图片（png/jpg，透明背景最好）丢进 avatars 文件夹，
刷新网页 → 设置 → 形象，就能看到。
